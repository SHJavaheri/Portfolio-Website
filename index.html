Python and Discord.py

Enhance your Discord server with AI-powered conversations and controls!

Github

Sortify

Python and Tkinter

Organize your folders/files with one click!

Github

Sortify is a compact yet powerful Python application designed to streamline your digital workspace. With just a few clicks, you can select any folder on your system and instantly organize its contents into designated, pre-defined folders. You have the flexibility to choose between two modes:

  • Singular: Organize the selected folder only, leaving all subfolders untouched.
  • Recursive: Organize all files within the selected folder and its entire directory tree, down to the deepest branch, ensuring no file is overlooked.

This tool is perfect for users looking to effortlessly bring order to cluttered directories, making file management faster and more efficient.

Spotify Music Player

Python and Tkinter

Control your music with a simple, intuitive player!

Github

Spotify Music Player is one of my first Python projects, designed with simplicity and functionality in mind. Built using Python and Tkinter, this application allows users to control their Spotify music seamlessly.

  • Playback Controls: Play, pause, and skip forward or back within the current song.
  • Navigation: Easily skip to the next track or return to the previous one with dedicated controls.
  • Simple Integration: Once Spotify is open, launch the player for an intuitive music experience.

This project showcases my early steps in programming and building practical desktop applications. It's a great lightweight tool for managing your music with ease!
